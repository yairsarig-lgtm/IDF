# צה"ל | רוטינה לקוסמים צבאיים מאת יאיר שריג

אפליקציית ווב אישית לקסם אחד: הקהל גולל בין תמונות של דברים ישראליים, ושלוש גלילות נעצרות תמיד על
**פחי צבע**, **קרם הגנה** ו**דגל ישראל**. המילה האחרונה בכל שם נכתבת על הלוח: צבע · הגנה · ישראל.

## איך זה עובד
- `index.html` – כל האפליקציה (מסך הגדרות + מסך הופעה). רשימת הפריטים מוטמעת בתוכו.
- `data/items.json` – 500 הפריטים. `q` הוא רמז חיפוש בעברית לוויקיפדיה, `en` רמז חיפוש באנגלית ל-Wikimedia Commons.
- `images/` – תמונה אחת לכל פריט (`t001.jpg` …) ושלוש תמונות הכפייה (`force-1.jpg`, `force-2.jpg`, `force-3.jpg`).
  `images/force/` מכיל כמה מועמדות לכל תמונת כפייה, לבחירה בעין.
- `images/credits.json` – מאיפה הגיעה כל תמונה. `images/missing.txt` – פריטים שלא נמצאה להם תמונה.
- `docs/` – הרשימה המלאה (1,705) ורשימת ה-500.

## הורדת התמונות
Actions ← **Fetch images** ← Run workflow. הסקריפט מוריד לכל פריט תמונה ברישיון חופשי מוויקיפדיה העברית
או מ-Wikimedia Commons, ושומר אותה ב-`images/`. הרצה חוזרת משלימה רק את מה שחסר.

החלפת תמונה ידנית: להעלות קובץ JPG באותו שם לתיקיית `images/`.

## שינוי רשימת הפריטים
לערוך את `data/items.json` ולהריץ `python scripts/build.py`.

## בהופעה
- הגדרות: כמה גלילות חופשיות לפני כל אחת משלוש הכפיות (ברירת מחדל 3 / 2 / 2, כלומר גלילות 4, 7 ו-10).
- גלילה נספרת רק כשזזים יותר מתמונה אחת והתנועה נעצרת לגמרי.
- אחרי כפייה המסך ננעל. נגיעה בפינה הימנית התחתונה משחררת.
- נקודה קטנה בפינה הימנית התחתונה: זהב = הגלילה הבאה כפויה, ירוק = נעול על כפייה.
- חזרה להגדרות: לחיצה ארוכה או 3 נגיעות מהירות בפינה השמאלית העליונה.
